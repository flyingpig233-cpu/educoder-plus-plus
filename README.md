# Educoder++

**把头歌作业、代码编辑、本地测试和在线评测，放进一个桌面工作台。**

Educoder++ 是使用 Rust 构建的头歌（Educoder）第三方桌面客户端。通过熟悉的代码编辑器完成实训，减少在网页、编辑器和终端之间反复切换，让注意力回到题目和代码本身。

[下载 Windows 版](https://github.com/flyingpig233-cpu/educoder-plus-plus/releases/latest) · [题目答案库（Gitee）](https://gitee.com/flyingpigcpu-233/educoder-answer) · [开发文档](docs/DEVELOPMENT.md)

## 为什么使用 Educoder++

### 一处完成整个练习流程

从「我的课堂」查看实训作业和关卡进度，打开工作区即可阅读题目、切换代码文件、运行样例、同步代码并提交评测。结果直接回到工作区，作业列表同步更新通过进度，减少重复查找和页面跳转。

### 更顺手的代码编辑体验

内置 Monaco 编辑器，支持多文件编辑、语法高亮、查找、代码折叠、快捷键和撤销操作。Markdown 题目与代码并排显示；深色、浅色、跟随系统主题，以及可收起的侧栏，适应不同屏幕和使用习惯。

编辑器、字体和 Markdown 资源随程序内嵌，启动无需 Node.js、开发服务器或在线 CDN。

### 自动保存与草稿保护

输入后自动保存本地草稿，停止输入后后台同步到头歌，也可使用 `Ctrl+S` 立即同步。切换关卡、返回列表和关闭窗口前等待草稿落盘；断网时保留修改，远端代码变化时以本地编辑内容为准同步覆盖。

保存、提交和查询结果分别处理。提交结果不确定时先查询评测状态，避免重复发起提交。

### 先在本机验证，再提交评测

支持 C、C++、Rust、Python、JavaScript 和 Java 的本地样例运行，可填写输入与预期输出，查看编译诊断、标准输出和错误输出。工具链路径可在设置中配置，并提供环境检查。

本地执行带超时和输出大小限制；平台公开测试结果直接展示，隐藏测试仅显示平台允许返回的信息。本机与平台环境可能不同，最终结果以平台评测为准。

### 连接方便，日常使用更连贯

Windows 版仅提供微信扫码登录，内嵌头歌官方二维码页面；手机确认并验证会话后存入 Windows 凭据管理器，下次启动自动恢复。

头像选项栏右侧的圆点统一表示连接状态：绿色为连接成功，红色为连接失败，呼吸式闪烁为正在连接，灰色空心圈为未登录。侧栏收起后仍显示状态圆点，头像菜单可覆盖代码工作区正常使用。

课程、作业和题目按会话分别缓存，刷新期间保留已有内容，断网时仍可查看已缓存资料。网络与磁盘操作在后台执行，界面呈现加载、同步、失败和登录过期状态。

### 国内可访问的答案参考

工作区内可查看 [Gitee 题目答案库](https://gitee.com/flyingpigcpu-233/educoder-answer)，按课程、作业及关卡精确匹配，支持多文件查看、复制，以及整文件或选中片段导入。导入支持撤销，之后按正常编辑流程同步，不会自动提交评测。

答案请求不携带头歌登录凭据；未收录题目明确提示。参考答案的本地验证状态不代表平台隐藏测试通过，使用前请理解代码并核对目标文件。

## 下载与开始使用

1. 前往 [GitHub Releases](https://github.com/flyingpig233-cpu/educoder-plus-plus/releases)，下载 `EducoderPlusPlus-1.2.0-windows-x64.exe`。
2. 将 EXE 放到任意目录直接运行，无需安装本项目、Rust 或 Node.js。
3. 点击「连接头歌账号」→「微信扫码登录」，扫码并在手机上确认后点击「已完成登录」。
4. 选择课堂和实训作业，进入关卡开始编辑。尚无个人实训实例时，需主动点击「进入实训」。
5. 按需运行本地样例，确认同步状态后点击「提交评测」，在工作区查看结果。

**运行要求：**1.2 发布包面向 Windows 10/11 x64，依赖 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。运行时通常已随系统或 Edge 安装，缺失时需先安装。本地编译运行需另行安装相应语言工具链，在线编辑与评测不要求安装这些工具链。

**单文件的含义：**应用代码、界面、图标和离线编辑器资源打包为一个 EXE，发布构建静态链接 MSVC C 运行库；WebView2 使用系统运行时。配置、缓存与草稿保存在系统用户数据目录，登录会话保存在系统凭据库，不随 EXE 移动到其他电脑。

## 当前范围

| 能力 | 1.1 状态 |
| --- | --- |
| 课堂、实训作业、关卡与代码文件浏览 | 支持 |
| 多文件编辑、草稿、后台同步、提交与结果查询 | 支持 |
| 本地样例运行、编译诊断、输出比较 | 支持，需本机工具链 |
| Gitee 答案查询、复制与导入 | 支持，以仓库收录内容为准 |
| 图文作业 | 支持列表浏览 |
| 官方微信扫码登录 | Windows 支持，扫码后在手机上确认 |
| Linux / macOS 发布包、评论系统 | 暂未提供 |

平台接入基于已观测协议，头歌接口变化可能影响部分功能。自动化测试使用模拟服务与合成数据，不依赖真实账号或在线提交；真实账号的保存、提交和网页登录完整流程仍需用户实际使用验证。

## 数据与隐私

不保存账号密码，不将 Cookie 或 Token 写入源码、日志或答案库请求。Windows 会话使用系统凭据管理器，退出登录会清除保存的会话。缓存与草稿包含已读取的题目及代码，保存在当前用户的数据目录，默认 Windows 路径为 `%LOCALAPPDATA%\Educoder\EducoderPlusPlus\data`。

## 开发与构建

采用 Cargo workspace：`crates/core` 提供异步平台接口、会话、缓存与本地执行；`crates/ui` 使用 Slint 和内嵌 WebView 提供桌面界面。

```powershell
npm ci --prefix crates/ui/web
cargo run -p educoder-ui
```

构建前需安装 Rust stable、Node.js/npm 和 Windows MSVC 构建工具。完整开发说明、接口边界和诊断命令见 [开发文档](docs/DEVELOPMENT.md)，单文件打包与可移植性验证见 [发布文档](docs/RELEASING.md)。
