# Educoder++ 1.0.0

首个 Windows x64 单文件正式版：把头歌实训浏览、代码编辑、本地样例和在线评测放进一个桌面工作台。

## 主要特点

- 内置离线 Monaco 编辑器与 Markdown 阅读，多文件编辑、快捷键、查找、折叠与撤销。
- 自动保存本地草稿，后台同步到头歌，提交评测与结果查询分别处理，保留断网及冲突时的编辑内容。
- 课堂、实训、关卡浏览与通过进度；按会话隔离缓存，刷新时保留已有内容。
- C/C++、Rust、Python、JavaScript、Java 本地样例运行，编译诊断、输出比较和工具链设置。
- Windows 官方网页登录、会话恢复与系统凭据存储；支持 Cookie 文件导入。
- 深浅主题、跟随系统、可收起侧栏、自绘标题栏和减少动态效果支持。
- 答案库迁移至 https://gitee.com/flyingpigcpu-233/educoder-answer，程序实际下载地址和界面来源同步更新，支持 Gitee 内容 CDN 重定向。
- 重写 README，突出项目特点和使用优势；开发说明、打包与验证步骤独立成文档。

## 下载与运行

下载 `EducoderPlusPlus-1.0.0-windows-x64.exe` 后直接运行，无需安装 Rust、Node.js 或本项目。发布构建静态链接 MSVC C 运行库，界面、图标及编辑器资源内嵌；无控制台窗口。

面向 **Windows 10/11 x64**，需已安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。本地样例运行另需对应编译器或解释器；在线编辑和评测不要求本地工具链。

配置、缓存和草稿保存在系统用户数据目录，凭据保存在 Windows 凭据管理器。移动 EXE 不会迁移账号和草稿。

提供 `SHA256SUMS.txt` 校验下载完整性，附带 `LICENSE` 和 `THIRD_PARTY_NOTICES.md`。

## 发布验证

实测环境：Windows 11 25H2 x64（build 26200），Rust 1.96.0、Node.js 24.16.0。

- `cargo fmt --all -- --check`、`cargo check --workspace` 通过。
- `cargo test --workspace`：42 项测试通过。
- `npm test --prefix crates/ui/web`：18 项测试通过。
- 实际答案客户端从 Gitee 读取索引和答案文件成功，未使用过期缓存。
- EXE 导入表仅含 Windows 系统 DLL，无需随包分发 VC Runtime 或 WebView2Loader DLL；GUI 子系统验证通过。
- 单独复制 EXE 到含中文、空格的新目录，PATH 仅保留 Windows 系统目录，正常启动并关闭。
- 相同发布构建下，合成数据测试验证离线 Monaco/Markdown、答案复制导入、原生 IPC、主题与窗口行为；三次工作区/列表切换均保留草稿，列表像素比较一致。
- 发布 EXE 的 SHA-256 与清单一致。

以上为本机搬移运行和资源验证，尚未在干净 Windows 虚拟机或其他系统版本验证。WebView2 仍是系统依赖。

## 已知边界

- 仅发布 Windows x64；图文作业当前仅提供列表，评论系统未实现，第三方 OAuth 登录弹窗暂不支持。
- 自动化测试使用模拟服务和合成数据；未使用真实账号执行保存、提交或完整网页登录验证。
- 平台接口变化可能影响功能；参考答案是否收录及平台隐藏测试结果以实际情况为准。
