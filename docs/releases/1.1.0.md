# Educoder++ 1.1.0

本次更新简化 Windows 登录流程，调整本地草稿与远端代码的同步行为，并优化欢迎界面。

## 更新内容

- 桌面端统一使用头歌官方微信扫码登录，扫码并在手机上确认后点击「已完成登录」。验证后的会话保存在 Windows 凭据管理器，下次启动自动恢复。
- 移除桌面 Cookie 文件导入入口和 `EDUCODER_COOKIES` 环境变量登录；核心库诊断工具仍支持 Cookie 文件导入。
- 远端代码变化时保留本地编辑内容，自动同步和提交以本地代码为准覆盖远端，无需手动处理冲突。旧版草稿仍可恢复。
- 刷新题目保留本地代码，简化草稿恢复提示；继续保留断网草稿、写入结果未知时暂停同步和提交状态查询机制。
- 调整欢迎页与登录文案，补充深浅主题、紧凑窗口、侧栏收起和加载状态的预览。
- 修复 Windows PowerShell 发布验证脚本偶尔无法读取已退出子进程退出码的问题。

## 下载与运行

下载 `EducoderPlusPlus-1.1.0-windows-x64.exe` 后直接运行。面向 Windows 10/11 x64，需已安装 Microsoft Edge WebView2 Runtime；无需安装 Rust 或 Node.js。本地样例运行另需对应语言工具链。

界面、图标和离线编辑器资源内嵌，发布构建静态链接 MSVC C 运行库。配置、缓存与草稿保存在系统用户数据目录，登录会话保存在系统凭据库。移动 EXE 不会迁移账号和草稿。

附带 `SHA256SUMS.txt`、`LICENSE` 和 `THIRD_PARTY_NOTICES.md`。
