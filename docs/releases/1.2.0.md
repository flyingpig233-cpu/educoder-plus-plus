# Educoder++ v1.2 · UI 界面更新

本次版本集中优化课堂导航、代码工作区与题解布局，版本号为 1.2.0。

## 更新内容

- 简化课堂与作业导航，使用作业分类 Tab、无边框返回及刷新图标，调整列表悬停反馈和完成进度显示。
- 头像旁统一显示连接状态圆点，连接中使用呼吸动画；收起侧栏后保留账号入口，账号菜单可覆盖代码工作区。
- 本地测试与平台结果改为无边框 Tab，调大并加粗文字，选中下划线以 220ms 平滑移动，自动适应窗口和布局变化。
- “查看答案”更名为“题解”。弹窗精简为文件选择、代码区和底部导入栏，来源与说明默认折叠，窄窗口自动调整操作布局。
- 保留题解多文件查看、复制、整文件覆盖、选中片段插入和撤销能力。
- 最大化动画前后刷新 Windows 边框缓存，修正标题栏样式切换未及时生效的问题；继续遵循系统减少动态效果设置。

## 下载与运行

下载 `EducoderPlusPlus-1.2.0-windows-x64.exe` 后直接运行。支持 Windows 10/11 x64，需安装 Microsoft Edge WebView2 Runtime；无需安装 Rust 或 Node.js。本地样例运行需另行安装对应语言工具链。

界面、图标和离线编辑器资源内嵌，静态链接 MSVC C 运行库。配置、缓存和草稿保存在系统用户数据目录，登录会话保存在系统凭据库。附带 `SHA256SUMS.txt`、`LICENSE` 和 `THIRD_PARTY_NOTICES.md`。

## 验证与边界

- `cargo fmt --all -- --check`、`cargo check --workspace` 通过。
- `cargo test --workspace`：43 项测试通过。
- `npm test --prefix crates/ui/web`：20 项前端回归测试通过。
- Windows x64 发布 EXE 的系统 DLL 依赖、GUI 子系统和 SHA-256 核验通过。
- EXE 单独放入中文空格目录、PATH 仅含 Windows 系统目录时正常启动和关闭。
- 相同静态运行库发布构建的合成数据示例验证窗口最大化/还原、离线编辑器、题解复制导入、账号菜单、主题和页面切换；三次工作区/列表往返保留草稿，列表像素差异为零。

以上为本机 Windows x64 搬移运行检查，尚未在干净 Windows 虚拟机或其他 Windows 版本验证。
- 已检查题解弹窗深浅主题与窄窗口布局，并验证下划线存在动画中间位置，减少动态效果设置下直接切换。

首次最大化闪烁已修正一处边框缓存时序缺陷，但尚未逐帧验证所有 DWM 动画中间帧，不保证所有设备上的首次闪烁均已消除。

自动化测试使用模拟服务和合成数据，未使用真实账号执行保存、提交或完整扫码登录验证。仅提供 Windows x64 发布包，图文作业仅支持列表浏览，评论系统未实现。平台接口和参考答案覆盖范围以实际情况为准。
